# 引用气泡回复

划选会话里的文字，点选区旁的「引用回复」，在弹窗里就地写回复。原文预览最多三行，悬停或点击可以看全文。

## 引用与草稿

- 要把多段原文放进同一条回复，点「＋ 再选一段」，划选下一段后点「加入引用」。已经写好的回复和光标位置会保留。
- 要单独回复下一段，先把当前回复加入草稿，再划选下一段并点「引用回复」。
- 气泡按添加顺序固定在聊天框顶部，普通草稿在下面。悬停气泡可看全文，点 `×` 可删除这一条。
- 用聊天框的发送按钮一次发出。原文以 Markdown 引用块发送，各条引用回复之间保留分段。

## 快捷操作

- 按 `Enter` 或点蓝色上箭头加入草稿。回复只有空白字符时按钮禁用。
- 按 `Shift+Enter` 换行。
- 按 `Esc`、点「Esc 取消」或点击弹窗外关闭。
