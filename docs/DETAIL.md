# 引用气泡回复

划选对话中的文字，点击选区旁的「引用回复」。气泡会显示最多三行原文。把鼠标移到预览上可看全文，也可以点击预览展开。

在气泡里输入回复，按 Enter 或点蓝色上箭头加入草稿。气泡按添加顺序固定在聊天框顶部，普通草稿在下面。悬停可以查看全文。点击聊天框的发送按钮时，消息会带上完整引用和回复，引用与正文之间空一行。

- 用 Shift+Enter 换行。回复为空或只有空白字符时，「加入草稿」为禁用状态。
- 按 Esc、点底部的「Esc 取消」或点气泡外关闭回复弹窗。
- 点「再选一段」，划选另一处原文后点「加入引用」。同一条回复可以引用多段文字，先写好的回复会保留。
- 要单独回复另一段时，先加入当前回复，再划选那段原文并点「引用回复」。
- 聊天框内每条引用回复都有独立的「×」。点它会一起移除本条引用和回复。
